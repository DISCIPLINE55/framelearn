# UI/UX Specification & Design Tokens — FrameLearn

## 1. Color Palette Tokens
| Token Name | Hex Code | Purpose |
|------------|----------|---------|
| `navy` | `#10212B` | Navigation, Footers, Key Headings, High Contrast Elements |
| `sage` | `#8FA464` | Brand Accents, Highlights, Secondary Buttons, Badges |
| `cream` | `#EFFBDD` | Main Page Background, Soft Section Surfacing |

## 2. Typography Rules
- **Display**: Outfit / Bold (Hero titles)
- **Headings (H1-H3)**: Outfit / Semi-Bold
- **Body & Controls**: Inter / Regular & Medium

## 3. UI Foundation Components
1. `Button` (Primary, Secondary, Outline, Ghost, Sizes: sm/md/lg)
2. `Input` (Label, Helper text, Error text, Disabled)
3. `Textarea`
4. `Select`
5. `Card` (Header, Content, Footer)
6. `Badge` (Navy, Sage, Cream, Outline)
7. `SectionHeading` (Eyebrow, Title, Subtitle, Alignment)
8. `Modal` (Dialog foundation, Backdrop, Accessibility)
9. `LoadingState` (Spinner & Skeleton preview)
10. `EmptyState` (Icon, Message, Action CTA)
11. `ErrorState` (Alert banner & Retry control)
12. `ImageContainer` (Aspect ratios, Lazy loading, Skeleton fallback)
13. `Container` (Max-width responsive grid wrapper)
14. `Navigation` (Responsive Header with mobile drawer & Footer)
