# Software Requirements Specification (SRS) — FrameLearn

## 1. Introduction
This document defines the Software Requirements Specification for the FrameLearn photography portfolio, service, and learning platform.

## 2. System Overview
FrameLearn bridges the gap between public portfolio exposure, client business management (bookings/galleries), and photography education.

## 3. Target Audience & Personas
- **Visitor / Potential Client**: Views portfolio, checks packages, submits booking requests.
- **Active Client**: Accesses private proofing galleries, downloads final assets.
- **Learner / Student**: Browses photography guides, enrolls in workshops, views tutorials.
- **Photographer (Admin)**: Manages site content, bookings, galleries, and educational materials.
