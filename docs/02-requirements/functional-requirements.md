# Functional Requirements Overview

## Core Functional Modules (Planned for Future Milestones)
1. **FR-1.0 Authentication & RBAC**: User registration, login, session persistence, role checking (Client, Learner, Admin). *(Milestone 002)*
2. **FR-2.0 Portfolio & Showcase**: Category filtering, lightbox viewer, photographer bio. *(Milestone 003)*
3. **FR-3.0 Service & Booking Engine**: Service package cards, date picker, inquiry form. *(Milestone 004)*
4. **FR-4.0 Client Gallery & Proofing**: Password access, image favoriting, zip downloads. *(Milestone 005)*
5. **FR-5.0 Learning Hub**: Course listings, lesson view, downloadable PDF guides. *(Milestone 006)*
6. **FR-6.0 Admin Dashboard**: Content management, booking review, gallery uploader. *(Milestone 007)*

## Milestone 001 Functional Deliverables
- **FR-0.1 Design System Tokens**: System palette (#10212B, #8FA464, #EFFBDD) applied via Tailwind CSS.
- **FR-0.2 Application Shell**: Header, Footer, and Navigation Shell.
- **FR-0.3 UI Core Components**: 14 foundational UI components with interactive demo states.
