# FrameLearn — Project Scope & Boundaries

## 1. In Scope (Target Platform)
1. **Public Portfolio & Brand Presentation**: Photographer bio, curated image galleries, service offerings.
2. **Client Booking Engine**: Session scheduling, package selection, status tracking.
3. **Private Client Galleries**: Password-protected proofing, high-res image delivery, selection favoriting.
4. **Educational Hub (Learning)**: Tutorials, workshops, photography guide downloads, student feedback.
5. **Photographer Admin Dashboard**: Client management, booking approvals, gallery publishing, content management.

## 2. In Scope for Milestone 001 (FOUNDATION ONLY)
- Project initial setup & TypeScript config.
- Tailwind CSS design token setup (`#10212B`, `#8FA464`, `#EFFBDD`).
- Responsive Application Shell (Header, Navigation shell, Responsive Container, Footer).
- 14 Reusable UI Foundation Components (Button, Input, Textarea, Select, Card, Badge, SectionHeading, Modal, LoadingState, EmptyState, ErrorState, ImageContainer, Container, NavFoundation).
- Folder Architecture structure matching specification.
- Test runner and CI setup.

## 3. Explicitly Out of Scope for Milestone 001
- Database tables creation (Bookings, Users, Galleries, Lessons, etc.).
- Authentication login/signup flows.
- Payment gateways.
- Live booking forms or photo uploads.
- CRM or notification dispatching.
